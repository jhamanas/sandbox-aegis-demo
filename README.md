# ⚡ SandBox v2.0 '26 — Post-Event Showcase & Archives

Official post-event website redesign for **SandBox v2.0**, organized by **Aegis Club**, Department of Computer Science & Engineering (Cyber Security), Dayananda Sagar College of Engineering (DSCE), Bengaluru.

This project transitions the pre-event registration portal into an always-on, single-scroll legacy showcase, winners hall of fame, and past-events archive—strictly preserving 100% of the original **Neo-Brutalist Cyber-Retro** brand identity.

---

## 🎨 Visual Identity & Theme
* **Canvas:** Warm cream / ivory (`#FFFBEB`) with technical blueprint grid lines.
* **Palette:** Neo-Yellow (`#FFDE59`), Cyber-Cyan (`#5CE1E6`), Neo-Pink (`#FF66C4`), Mint (`#DCFCE7`), Sky Blue (`#E0F2FE`).
* **Borders & Shadows:** Solid black borders (`border-4 border-black` / `border-2 border-black`) with hard, unblurred offset drop shadows (`4px`, `6px`, `8px`, `10px`).
* **Typography:** Bold uppercase `Space Grotesk` headers paired with playful handwritten `Caveat` doodle stickers and `JetBrains Mono` counters.
* **Animated Ticker:** Signature `#FFDE59` yellow marquee ticker tape (`"BUILD • BREAK • CREATE • SANDBOX..."`).

---

## 🚀 Key Sections & Features
1. **Sticky Cyber-Navbar:** Fixed header with brand badge, scrollspy navigation anchors, Discord community link, and SandBox v3.0 Early Access button.
2. **Hero & Marquee:** Wrap-up celebration headline, "Ctrl+F Your Team, Legend" doodle linking to Selected Teams, Title Sponsor (Hacker School) callout, and interactive confetti trigger.
3. **Impact Metrics Strip:** 6 pastel brutalist KPI cards highlighting 24h hacking, 320+ builders, 64 deployed projects, 8 defense tracks, ₹50,000+ prize pool, and 45+ colleges represented.
4. **Hall of Fame & Track Champions:** 
   - Top 3 Overall Grand Champions (#1 *SentinelZero*, #2 *ChainGuard*, #3 *DarkPulse*) with tech stack tags, member lists, and GitHub/demo links.
   - Filterable category grid for all 8 tracks (*Threat Detection, AI Copilot, AppSec, Web3 Security, Data Privacy, Gamification, Dark Web, Open Innovation*).
5. **24-Hour Experience:** 4K Aftermovie spotlight card + chronological timeline milestones from Day 1 Check-in to Day 2 Valedictory.
6. **The Aegis Chronicles (Past Events Archive):** Master-Detail interactive timeline showcasing *SandBox v2.0 '26, GlitchCraft '26, SandBox v1.0 '25, ByteCon '24*, and upcoming *SandBox v3.0 '27*.
7. **Visual Media Gallery:** Category-filtered photography grid (*Hacking Floor, Mentors & Jury, Midnight Chaos, Awards & Podium*) with full-screen Neo-Brutalist lightbox viewer.
8. **Wall of Gratitude (Sponsors):** Title Sponsor spotlight for Hacker School, plus partner cards for DERBI Foundation, Sagar Hospitals, Nopal, and SecPod, along with mentor gratitude.
9. **Organizing Crew & Footer:** Aegis Club & Dept. of CSE (Cyber Security) spotlight, student coordinators (Samarth BC, Kanishk Singh), campus address, Devfolio portal link, socials, and Back-to-Top button.
10. **SandBox v3.0 Waitlist Modal:** Lead-capture popup for hackers to get priority alerts for the 2027 edition.

---

## 🛠️ Tech Stack
* **Framework:** React 19 + Vite 8
* **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`) with custom Neo-Brutalist primitives
* **Icons:** Lucide React
* **Effects:** Canvas-Confetti
* **Design Proposal:** `SandBox_PostEvent_Redesign_Proposal.docx` (included in repository)

## 💻 Local Setup & Development

```bash
# Clone the repository
git clone https://github.com/jhamanas/sandbox-aegis-demo.git
cd sandbox-aegis-demo

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
